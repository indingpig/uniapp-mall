## 1. 设计语言

- 气质：温暖、安心、低刺激（婴儿家庭监护场景）
- 暖奶油底 `#F4EDE1` 承载白色大圆角卡片；橄榄绿为唯一强主色（平稳/安全）
- 琥珀 = 留意、珊瑚红 = 立即提醒，**红色只用于哭闹/立即推送**，不大面积铺
- 宝宝表情双轨制：**首页大表情 = 品牌暖橙 `#E8825A` 固定不变**（亲和、不焦虑）；**图例/事件流小图标 = 状态色**随语义走
- 圆角大（卡片 16–20、按钮/TabBar 胶囊）、图标线性圆角风（**统一 2px 描边 @24 viewBox**）、近乎平面（极淡投影）

## 6. 宝宝状态语义（5 态，终版）

```ts
type BabyState = 'sleep' | 'awake' | 'active' | 'noise' | 'cry'
```

| 状态 | 取色 | 判定 | 动作 | 徽章 |
|---|---|---|---|---|
| 安睡 sleep | 绿 | 呼吸平稳，音量持续低于阈值 | 仅记录 | 仅记录（绿） |
| 清醒 awake | 琥珀 | 有咿呀声，短暂清醒活动 | 仅记录 | 仅记录（绿） |
| 清醒活跃 active | 橙 | 持续发声，音量中等且起伏大 | 记录+事件 | 记录+事件（琥珀） |
| 有动静 noise | 中性灰 | 翻身等非哭声音响，短暂出现 | 记录+事件 | 记录+事件（琥珀） |
| 哭闹 cry | 红 | 哭声特征匹配，持续升高 | **立即推送** | 立即推送（红） |

**状态机**：主状态两态切换 `sleep ⇄ awake`（音量阈值 + 时长窗口判定；浅睡已裁掉——纯声音检测不可靠）；`noise / cry` 为事件层，不改变主状态，以事件形式进时间线。状态切换事件（「开始安睡」「开始清醒」）同样写入时间线。
**红色红线**：red 仅用于 cry / 立即推送 / 退出登录 / 未读红点，其余状态一律绿/琥珀/橙/灰。
**双轴说明（勿混淆）**：「取色」列 = 该状态的**表情/图标底色**（状态语义）；「徽章」列 = **动作级别色**（绿=仅记录、琥珀=记录+事件、红=立即推送），两者独立——所以清醒是琥珀图标+绿徽章，这是设计意图，不是笔误。

## 7. 音量条映射（开发公式）

```
MIN = 30                        // 未开校准
MIN = max(30, N + 5)            // 开启底噪校准后（N = 安装时采集的环境底噪基线）
音量% = clamp((dB - MIN) / (90 - MIN), 0, 1)   // MIN–90 dB → 0–100%
```
- 结构：三分区底（**宽度 60%/20%/20% 相对轨道，轨道宽 = 卡片内容宽 100%，禁止固定 318px**）→ 深绿填充层（宽度=音量%）→ 白色游标（14px，绿描边 3px，`left = calc(音量% − 7px)`）
- 示例自洽：MIN=30 时 55dB → 41.7% ≈ 42%（与设计稿游标位置一致）
- **量程下界（修正）**：0 dB SPL 是人耳听阈参考值，真实环境不可能出现——婴儿房夜间底噪约 28–35 dB，设备端（INMP441 未校准）显示值为相对声压级，同样不会出现 0。**显示值 <30 dB 一律视为环境底噪 → 空条 + 文案「安静」**（"静音"另有所指：是用户设置的提醒开关，勿混用）；仅离线/无数据时显示「-- dB」
- **底噪校准（建议 P1）**：昼夜底噪差异大，固定 30 dB 下限可能白天误判。建议设备安装后采集 10s 环境底噪得基线 N，按上方公式的 MIN = `max(30, N+5)` 生效；哭声阈值同步随基线偏移。INMP441 未校准，阈值需实测定标
- 分区阈值 60%/80% 与提醒策略联动，阈值可由设置页灵敏度派生

## 15. 微信小程序端约束（v1.1.10 改为备用渠道，启用前逐条确认）

> 小程序改为**备用渠道**：App/H5 先行，以下约束**不阻塞首发**；待小程序立项启用时再逐条落实（含决策点 #1/#2）。

### 15.1 网络架构（启用小程序时的决策点 #1）
- 小程序只能请求**合法域名白名单**内的 `wss/https`（须 ICP 备案），**不支持局域网 IP 直连**
- 若届时后端仍在局域网：**必须公网部署**（云服务器 + 备案域名 + TLS 证书），ESP32 改为上报公网服务器
- **App 端无此限制**：可直连局域网地址（http/ws 均可，无白名单/备案要求），开发期 ESP32 + Node 留在局域网即可联调；生产环境建议仍迁公网 + TLS

### 15.2 推送机制（启用小程序时的决策点 #2）
- 小程序无常驻推送；切后台约 5s 连接挂起，进程被杀即失联
- 哭声"立即推送"在小程序 = **微信订阅消息**：一次性订阅需**每次触发前用户授权**；长期订阅仅政务/民生等类目，育儿工具大概率不可用
- 产品策略二选一（建议组合）：**A.** 推送主阵地放 App（厂商通道离线推送），小程序承担实时查看/配对/历史；**B.** 小程序内引导用户批量授权一次性订阅，覆盖短期场景
- **App 首发 = 哭声提醒走厂商通道（华为/小米/OPPO/vivo Push + APNs），真·离线推送，无授权摩擦**——这是 App 优先的核心产品价值
- 监听中态仅前台有效（见 12.3 补充）

### 15.3 音频播放
- 前台播放 PCM 流：`WebAudioContext`（基础库 ≥2.19.0）可行
- 后台播放：`BackgroundAudioManager` 受类目与合规限制，**小程序端**监听定位为"前台实时"
- **App 端可后台监听**：iOS 开 Background Modes（audio）、Android 用前台服务常驻通知——App 首发，设计稿 12.3 监听中态无需"前台"限定

### 15.4 登录与合规
- 登录：`wx.login`（openid/unionid）+ 手机号快捷授权组件
- 上架材料：隐私协议、用户隐私保护指引（收集麦克风数据说明）、类目资质（育儿/硬件相关）
- 音频采集在设备端完成，App/小程序仅接收——隐私声明需如实描述

### 15.5 包体积
- 主包 ≤2MB：图标走 iconfont + PNG 很小，无风险；禁止把设计稿 HTML 打进包里

### 15.6 图标形态（已全部交付）
- 28 个单色图标 → **iconfont 字体已交付（v2 重建版）**：`宝宝监控App-图标库/iconfont/`（baby-monitor.ttf/.woff/.woff2，woff2 2.7KB + `baby-monitor.css`（H5/App，路径 /static/fonts/）+ `baby-monitor-icons.wxss`（**小程序用，woff2 已 base64 内嵌**）+ `class-mapping.md`（28 个类名映射）+ README）。类名 = `bmi-` + 图标名，颜色走 CSS color，尺寸走 font-size
- **v2 重建说明**：v1 版用 svgicons2svgfont 直接转描边 SVG，描边不被转轮廓导致字形退化（镂空填死/线条发丝）；v2 改为 Skia `getFillPath` 先将描边转高质量填充轮廓、再用 fontTools 直接构建字体（绕向可控，nonzero 下镂空正确），字形与原 SVG 逐像素对齐（opentype 渲染比对验证通过）。构建脚本：主工作区 `iconfont-build/outline_v3.py`（改 SVG 后重跑）
- 7 个多色表情/插画 → **PNG @3x 已交付**：`宝宝监控App-图标库/png3x/`（face-* 84px、face-sleep-offline 228px、monitor-wave 144px，sharp 渲染，透明底）
- 多色图标**不走 iconfont**：字体 glyph 只能单色；iconfont.cn 的"彩色图标"实为 SVG symbol 方案（依赖 WXML 内联 `<svg>`，小程序不支持），COLR 彩色字体在小程序 `wx.loadFontFace` 渲染不可靠——勿尝试
- `BaseIcon.vue` 条件编译：`#ifdef H5 || APP-PLUS` 内联 SVG / `#ifdef MP-WEIXIN` 单色走 iconfont、多色走 `<image>` + PNG
