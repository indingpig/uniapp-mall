## 四、新增一屏 / 一个新状态，按这 5 步走

1. **画布**：主画布对应排末尾追加一板（390×844，标注文字放板上方 40px 处），命名 `页面 · 状态`；
2. **导出**：PNG @2x 放进 `v1.1-设计稿导出/`，命名 `NN-页面名-状态.png`，**NN 从 24 顺延**（当前最大 23，共 35 张）；同页多状态共用 NN + 状态后缀；新增屏可用 `.workbuddy/scripts/gen_new_screens.py` + `render_screens.js` 由 SVG 批量渲染（SVG 中间产物在 `D:\workbuddyplace\.baby_export_tmp\svgs\`）；
3. **规范**：第 5 节页面清单补一行 → 新增 5.x / 12.x 规格 → 第 11 节待补清单移除该项 → 修订记录版本号 +1；
4. **图标**（若有新增）：SVG 入 `宝宝监控App-图标库/` → 单色拷进 `iconfont-build/svgs/` 重跑 `outline_v3.py` → 多色用 sharp 出 PNG @3x → 重跑 `gen_preview.py` 更新预览页；
5. **收尾**：把新板/新图写进当日工作日志，并用 `present_files` 呈现新导出图。

## 六、红线（别踩）

- 交付物只进本目录，**不要往 `2026-09-27-xx` 时间戳目录里放新产物**；
- 多色图标不进 iconfont（字体 glyph 只能单色；小程序不支持内联 SVG）；
- 柱状图 X 轴标签必须逐柱绝对定位、以柱中心为锚，禁止整体居中文本凑位（规范 5.3）；
- 独立可点 cell `min-height ≥ 44`，内容撑开不裁切（规范 8）；
- 平台优先级：App 首发 → H5 兜底 → 微信小程序备用（规范 15，启用前过确认清单）。
